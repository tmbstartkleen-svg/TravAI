# TravAI Elite v7.3 — Multimodal Intelligence

Adds a local multimodal intake and evidence layer. Images receive type, dimensions, size and SHA-256 provenance. PDFs use local page/text extraction when a parser is available. Local Ollama vision-capable models are discovered rather than assumed. Scanned-only or unsupported content is reported honestly instead of fabricating OCR.

The v7.2 deployable control surface remains included; the Mac remains authoritative for private files and local models.

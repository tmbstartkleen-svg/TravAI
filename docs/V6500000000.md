# TravAI Elite v6.5B — Autonomous Coding Team

Adds a governed five-role engineering team: Architect, Coder, Tester, Reviewer, and Release Guardian.

## Safety model
- Offline-first planning
- No arbitrary shell added
- No silent mutation
- Coder mutation requires explicit approval
- Declared verification commands only
- Independent review before release
- Checkpoint and rollback evidence required

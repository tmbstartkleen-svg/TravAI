# TravAI Elite v6.8B — Native Mac Operator + Offline Capability Expansion

v6.8B adds typed native macOS/workspace actions above the offline-first coding, memory, repository-intelligence, model-routing, and always-on systems.

## Capabilities
- macOS application discovery and guarded launch
- Finder reveal for workspace items
- workspace create/copy/move/soft-trash
- local notifications
- process inventory and approval-gated termination
- Keychain service/account references without returning secret values
- persistent action ledger

## Safety
- no arbitrary shell endpoint
- explicit approval before consequential execution
- file mutations stay inside TravAI workspace
- deletes use soft trash
- Keychain secret values are never returned
- localhost binding remains the default

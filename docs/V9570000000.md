# TravAI Elite v9.5.7 — Mac Secure Bridge Authority

v9.5.7 is the Mac-local authority layer for TravAI's Vercel pairing flow.

## Local authority behavior
- Vercel-origin browser may submit a 128-bit random pairing request.
- Browser cannot approve, deny, or revoke a pairing.
- Approval/denial/revocation endpoints accept local-origin requests only.
- Pair requests expire after 5 minutes.
- Approved sessions expire after 15 minutes.
- Browser receives the session credential only once, after local approval.
- Unknown scopes are discarded.
- Default approval is read-only: health + readiness.

## Security boundaries
- arbitrary shell: disabled
- unrestricted filesystem: disabled
- secret export: disabled
- automatic firewall/IDS mutation: disabled
- Assessment Integrity bypass: disabled
- silent cloud fallback: disabled

# TravAI Elite v6.5B — Autonomous Coding Team

TravAI is an offline-first local AI engineering and workstation platform. v6.5B adds a governed multi-role coding team while preserving the Elite black/gold shell and prior backend engines.

## v6.5B highlights
- Architect, Coder, Tester, Reviewer, and Release Guardian roles
- Mission decomposition and acceptance criteria
- Baseline verification before implementation
- Approval-gated consequential mutations
- Regression testing and independent review
- Release checkpoint and rollback evidence
- Localhost-by-default runtime
- No unrestricted shell execution

## Start
```bash
npm start
```
Then open `http://127.0.0.1:4783/?v=6500000000`.
